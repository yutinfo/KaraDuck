# ชุดทดสอบ: YouTube ยอมให้ฟังก์ชันบน Vercel ค้นเพลงไหม

ของทดลอง ไม่ใช่ส่วนของแอป ใช้ตอบคำถามเดียว: การค้นหาและการตรวจเพลงที่ฝังได้ (ช่องทางไม่เป็นทางการของ YouTube)
ทำงานจาก IP ศูนย์ข้อมูลของ Vercel ได้ไหม ก่อนจะย้ายแอปไป Vercel + Firebase

- `api/search.js`, `api/embeddable.js` — เรียก `lib/youtube.mjs` (สำเนาจาก `lib/youtube.mjs` ของแอป) แล้วรายงานสถานะ HTTP และเวลา
- `index.html` — หน้ากดทดสอบ: ค้น 24 ครั้ง + ตรวจเพลง 20 เพลง
- `local.mjs` — รันชุดเดียวกันบนเครื่องตัวเองเพื่อเทียบ (`node local.mjs` → http://localhost:8793)
- ถ้าตั้งตัวแปร `TEST_KEY` ทุกคำขอต้องส่ง `?key=` ให้ตรง

## ผลวันที่ 24 พ.ย. 2026 (ภูมิภาค sin1 สิงคโปร์)

| ชุด | ผล |
|---|---|
| ค้นต่อเนื่อง 48 ครั้ง (คำค้นไม่ซ้ำ) | ผ่าน 48/48 · YouTube ตอบ 414–924 ms (กลาง 569) |
| ค้นพร้อมกัน 12 ครั้ง × 3 รอบ | ผ่าน 36/36 · ไม่มี HTTP 429 หรือหน้ายินยอม |
| ตรวจเพลงฝังได้ 20 เพลงจากผลค้น | ได้คำตอบครบใน 771 ms |
| เพลงที่รู้ว่าฝังไม่ได้ (`8oWgHgf_c_w`) | ตอบ `false` ตรงกับเครื่องที่บ้าน |

ข้อสังเกต:
- ผลตรวจเพลงขึ้นกับ `Referer` ที่ส่งไป: ถ้าเป็นเลข IP (`127.0.0.1`) เพลงค่ายใหญ่บางเพลงจะกลายเป็น "ฝังไม่ได้"
  เวอร์ชันออนไลน์จึงต้องส่งโดเมนจริงของเว็บเป็น `Referer`
- เป็นการทดสอบครั้งเดียวราว 110 คำขอในไม่กี่นาที ยังไม่ได้พิสูจน์ว่าใช้ต่อเนื่องทั้งคืนแล้วไม่โดนจำกัด

## Deploy

```bash
vercel deploy --prod --yes -e TEST_KEY=<รหัสสุ่ม>
```

ลบโปรเจกต์เมื่อเลิกใช้: `vercel project rm vercel-yt-test`
